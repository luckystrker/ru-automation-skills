# Яндекс Лавка — приватное веб-API из залогиненного браузера

> API приватное: дёргается **сайтовым fetch'ем из вкладки**, поэтому работает с куками и CSRF
> профиля. Обычным `curl` снаружи не получится — сессия живёт в браузере.

## Быстрый старт

```sh
cd scripts                                 # каталог со скриптами (см. README)

xvfb-run -a node stores/lavka.mjs probe            # адрес, корзина, проверка поиска (ничего не меняет)
xvfb-run -a node stores/lavka.mjs search "молоко"  # поиск с ценами
xvfb-run -a node stores/lavka.mjs cart             # корзина
xvfb-run -a node stores/lavka.mjs demo             # демо-корзина: молоко, хлеб, яйца
xvfb-run -a node stores/lavka.mjs screenshot       # скриншот страницы корзины
```

## Как устроено

- Скрипт `stores/lavka.mjs` открывает **залогиненный профиль** `stores/browser-profile-lavka`
  (headed под xvfb, российский SOCKS5-прокси `127.0.0.1:8890`), заходит на `lavka.yandex.ru`
  и выполняет `fetch` **из страницы**: куки сессии и CSRF подставляются сами.
- Город задаётся переменной `LAVKA_CITY` (числовой код города Яндекс.Карт, по умолчанию
  прописан в скрипте под нужный регион).
- CSRF берётся из HTML страницы (`"csrfToken":"…"`), заголовки —
  `x-requested-with: XMLHttpRequest`, `x-lavka-web-locale: ru-RU`, `x-lavka-web-city: <код>`.

## Эндпоинты (все POST, база `/api/v1/providers/...`)

| Назначение | Путь |
|---|---|
| Адреса | `/address/v1/get-favorite-addresses` |
| Корзина (чтение) | `/cart/v1/retrieve` |
| Корзина (запись) | `/cart/v1/update` |
| Поиск | `/search/v3/lavka` |

## Вход (если сессия истекла)

- `stores/lavka-login.mjs` — полный вход: телефон → SMS-код → имя и фамилия при регистрации →
  выбор аккаунта из объединённых профилей Яндекса.
- `stores/lavka-login-continue.mjs` — продолжить с шага после SMS.
- `stores/lavka-check.mjs` — проверить, что вход жив.
- Капча — Яндекс SmartCaptcha: проходится **кликом чекбокса в реальном браузере** (headed под xvfb),
  в headless не проходит.
- Телефон и код передаются в скрипт снаружи, в репозитории не хранятся.

## Грабли

- **Только headed**: headless Яндекс режет капчей и не отдаёт сессию.
- **Только через профиль**: `browser-profile-lavka` хранит логин; без него API отвечает 401.
- Профиль нельзя занимать двумя процессами одновременно (lock каталога): перед запуском
  убедись, что предыдущий `lavka.mjs` завершился.
- CSRF-токен живёт со страницей: не кешируй между запусками, бери заново из HTML.
- Минимальный заказ и стоимость доставки — в ответе `cart`; «Итого: 129 ₽» при пустой корзине —
  это доставка, а не товары.
- Цены в ответах — **в рублях** (в отличие от Магнита, где копейки).
- Заказ не оформляем сами: доводим до корзины, оплату и подтверждение делает человек.
