# RU Automation Skills

Скиллы для AI-агента: автоматизация российских продуктовых магазинов — поиск товаров с ценами,
сборка корзины, вход и проверка заказа. Формат — `SKILL.md` с YAML-заголовком (`name`, `description`),
который читают pi, Claude Code и совместимые агенты.

## Что внутри

| Скилл | Магазин | Как работает |
|---|---|---|
| [`yarche`](yarche/SKILL.md) | Ярче+ (yarcheplus.ru) | Chromium через российский SOCKS5, вход по SMS + KDV ID, антибот QRATOR |
| [`lavka`](lavka/SKILL.md) | Яндекс Лавка (lavka.yandex.ru) | приватное веб-API, дёргается `fetch`'ем из вкладки залогиненного профиля |
| [`magnit`](magnit/SKILL.md) | Магнит (magnit.ru) | внутренний API `webgate`: заголовки, магазины, поиск, корзина, вход по SMS |

Общее у всех трёх: нужен **российский IP** (магазины не открываются с зарубежных),
**headed-браузер** (капчи не проходят в headless) и **живой аккаунт** для корзины.

## Требования

- Node.js 22.19+ и Playwright с Chromium;
- `xvfb-run` для виртуального экрана (Linux);
- SOCKS5-прокси с российским выходом, доступный на `127.0.0.1:8890` (SSH-туннель или свой);
- аккаунт в магазине и доступ к SMS владельца аккаунта;
- скрипты-обёртки из вашего проекта в `stores/` и `tools/` (см. разделы «Готовые скрипты» в каждом скилле).

## Как подключить

```sh
git clone https://github.com/luckystrker/ru-automation-skills.git
cp -r ru-automation-skills/{yarche,lavka,magnit} ~/.pi/agent/skills/
```

Дальше агент сам подхватит скиллы: в описании каждого написано, когда его применять.

## Важно понимать

- **Это приватные API сайтов, а не официальные.** Формат запросов и заголовков может измениться
  в любой день — тогда правим скилл по живому сайту (DevTools → Network).
- **Капчи и антибот** (QRATOR у Ярче, SmartCaptcha у Яндекса и Магнита) проходятся только
  реальным браузером; в headless всё падает.
- **Оплату агент не делает.** Доводит до корзины и страницы оформления, дальше человек.
- **Персональные данные не храним**: телефон и коды передаются в скрипты аргументами и файлами,
  адреса подтягиваются из профиля. В репозитории их нет.
- Проверяйте правила магазинов: автоматизация может нарушать их ToS, аккаунт может быть заблокирован.
