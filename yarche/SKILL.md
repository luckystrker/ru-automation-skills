# Ярче+ (yarcheplus.ru)

Магазин открывается только с российского IP: браузер ходит через SOCKS5-прокси
(`socks5://127.0.0.1:8890` — SSH-туннель или любой другой российский выход).

## Что уже проверено

* Вход по SMS работает: телефон → SSO KDV ID → код. После входа сессия живёт в профиле
  браузера `stores/browser-profile`, повторный вход не нужен.
* Поиск, карточки товаров и добавление в корзину работают (минимальный заказ — 500 ₽).
* Пакетная сборка корзины по списку: `stores/yarche-fill-cart.mjs` — фильтры по названию,
  чтобы «картошка» не превратилась в сырок «Картошка».

## Быстрый старт

```sh
cd scripts                                 # каталог со скриптами (см. README)

node stores/yarche.mjs search "молоко" --limit 10   # поиск: имя, цена, наличие
node stores/yarche.mjs search "сыр" --json          # то же машинночитаемо
node stores/yarche.mjs cart --profile               # корзина (с логином)
```

Поиск идёт по URL `https://yarcheplus.ru/search?query=<запрос>`; карточки — элементы
`[class*="product-card-template"]`, кнопка добавления — `button:has-text("В корзину")`.

## Вход (для повторения)

```sh
xvfb-run -a node stores/yarche-login.mjs <телефон>   # headed, под виртуальным экраном
```

1. Скрипт вводит телефон и открывает SSO KDV ID.
2. Галочку согласия принимает только настоящий клик мышью по координатам (кастомный чекбокс).
3. При появлении капчи скрипт кладёт скриншот в `/tmp/yarche-captcha.png` и ждёт текст
   в `/tmp/yarche-captcha.txt`.
4. SMS-код ждёт в `/tmp/yarche-code.txt` — в файл положить цифры.
5. Браузер обязан быть видимым (headless режет QRATOR), поэтому запуск через `xvfb-run`.

Телефон в скрипт передаётся аргументом — в репозитории он не хранится.

## Корзина и оформление

```sh
node stores/yarche.mjs --profile cart                       # корзина
node stores/yarche.mjs add "молоко" --index 1 --qty 2       # добавить первый результат поиска
node stores/yarche.mjs add "хлеб" --index 3 --profile       # с сохранённым профилем
```

Пакетная сборка по списку (фильтры по названию, отчёт по каждой позиции):

```sh
node stores/yarche-fill-cart.mjs --list stores/yarche-shopping.json
node stores/yarche-fill-cart.mjs --list stores/yarche-shopping.json --dry   # только подбор
node stores/yarche-price-list.mjs --out /tmp/prices.json                   # варианты с ценами
node stores/yarche-quick.mjs "молоко 2,5%" "творог"                        # быстрый поиск
```

Оплату агент не делает: доводим до страницы оформления, дальше платит человек.
Скриншоты для отладки: `--screenshot /путь.png`.

## Адрес

Страница адресов: `https://yarcheplus.ru/profile/address` (список) и `/profile/address/create`.
Поле улицы — виджет Яндекс.Карт: `suggest-maps.yandex.ru` обычно работает, а
`api-maps.yandex.ru` периодически отдаёт 429 датацентровым IP, поэтому подсказки то есть, то нет.
Смена адреса надёжнее — в приложении «Ярче Плюс»: адрес хранится на сервере и подхватится в сессии.

## Грабли

- **Только headed**: headless палится QRATOR, капча рисуется пустой.
- На форме кода в KDV ID чекбокс «Я принимаю условия» надо кликать вручную, иначе «Отправить»
  серая; вкладку между попытками не закрывать — старый код умирает вместе с ней.
- Капча QRATOR при добавлении в корзину не появляется, если профиль залогинен и адрес задан.
- Цены и наличие меняются: перед заказом перечитывать, а не полагаться на старый прогон.
- Магазин не любит автоматизацию: не частить с входами, один запрос SMS за попытку.

## Проверка окружения

```sh
systemctl --user status <юнит-туннеля>                 # SSH-туннель до российского выхода
curl -s --proxy socks5h://127.0.0.1:8890 https://api.country.is/   # должен быть RU
node stores/verify-proxy.mjs                            # полная проверка магазинов
```
